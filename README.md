# Mobile Connection Database

Учебная база данных для учета абонентов мобильной связи.  
Проект выполнен в рамках расчетно-графической работы по дисциплине «Базы данных».

---

## Цель работы
Разработать и реализовать реляционную базу данных для предметной области  
**«Мобильная связь»**, включающую абонентов, SIM-карты, тарифы и дополнительные услуги,  
а также обеспечить целостность данных с помощью ограничений, процедур и триггеров.

---

## Сущности предметной области
- **Abonent** — абоненты мобильной связи  
- **Tariff** — тарифные планы  
- **SimCard** — SIM-карты  
- **Service** — дополнительные услуги  
- **ServiceConnection** — подключение услуг к SIM-картам (связь M:N)

---

## Используемая СУБД
**PostgreSQL 16**

---

## Особенности реализации
- первичные и внешние ключи  
- ограничения `UNIQUE`  
- каскадное удаление (`ON DELETE CASCADE`)  
- функция добавления абонента с SIM-картой  
- триггер автоматического подключения услуги  
- реализация связи **многие-ко-многим**
